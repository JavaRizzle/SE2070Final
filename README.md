# SE2070Final
Final project for Software Engineering 2070. A time management program that allows updating and viewing a log of hours work, weekly and daily goals for hours worked, daily goals, weekly goals, one-off goals, and completed tasks for my self-employed work restoring classic cars with my dad. Additionally, there is a section to record general creative ideas, ideas to streamline the physical work, and business idea. Finally, it allows the user to create clients with fields and methods that track important information to remember such as personal details, their cars, goals for those cars, and when they were last reached out to.
