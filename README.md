# SE2070Final
Final project for Software Engineering 2070. 
A work log and car progress tracker for restoring classic cars with my dad.


Features: 
- Loops through 12 menu options that let the user manipulate a ShopManager instance holding 2 initially empty ArrayLists
  - cars: holds Car objects (ArrayList)
  - log: holds WorkLog objects (ArrayList)
- Will continue ask for input until the user exits the program

=== Shop Manager ===
- Cars options
1. Add a car
2. Delete a car
3. Advance car work stage
4. View all car reports
5. View car report by name

- Work log options
6. Add a log
7. Delete a log
8. Clear all logs
9. View a log
10. View all logs
11. View total hours worked

0. end the program
=====================


How to run: 
1. download SE2070Final.zip
2. unpack and open with your IDE of choice
3. click run and follow the instructions printed in the terminal
4. enter 0 in the menu to exit the program.
